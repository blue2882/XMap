Mind Maps (iPad-friendly web app)

Host this folder on any static HTTPS site, then install on the iPad:
- Netlify Drop: drag this folder onto app.netlify.com/drop.
- GitHub Pages: put these files in a repo and turn on Pages.
On the iPad: open the site in Safari > Share > Add to Home Screen.

Features:
- iOS-inspired light/dark interface.
- Mind maps save automatically in this browser on this device.
- Create folders, filter by folder, and move maps between folders.
- Use Full screen in the editor for an edge-to-edge map; tap Exit full screen to return.
- Export individual maps as JSON for backup and transfer; import JSON backups on another device.
- The app runs offline after it has been loaded once.

Storage note:
This is a static app, so it does not include account login or cloud synchronization. Local saves remain in the same browser/device and can be lost if browser data is cleared. For cross-device account-based syncing, a backend and authentication provider must be configured. Use Export map regularly as a backup.
