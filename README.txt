Mind Maps (iPad app)

Host this folder on any static HTTPS site, then install on the iPad:
- Netlify Drop: drag this folder onto app.netlify.com/drop.
- GitHub Pages: put these files in a repo and turn on Pages.
On the iPad: open the site in Safari > Share > Add to Home Screen.
It then runs full screen and offline. Maps live on the device; use Export to back up.
