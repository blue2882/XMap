To install: tap the Share button in Safari, then Add to Home Screen. The app then opens full screen and works offline. Maps are stored on this device, so use Export on a card to keep a backup.

With AI on, the text and speaker notes of each deck are sent to Anthropic to build the map. Your key stays on this device and goes only to api.anthropic.com. Usage is billed to your Anthropic account. Without a key, imports use a basic offline draft.

Import options

Tell the AI how you want your mind map organized. For example: “Use a clean, balanced hierarchy like a textbook mind map: major topics as main branches, related details as children, and examples or definitions as smaller leaves. Keep sibling labels parallel and avoid crowded branches.”

These instructions guide AI-generated maps from PowerPoint files. JSON mind maps are imported as-is. If AI import is off or no API key is set, the request cannot change the basic offline draft.
